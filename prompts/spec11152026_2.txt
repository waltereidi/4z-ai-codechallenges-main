## 4. Reinício de Estado a Cada Reload/Reinício do Browser e Identificação de Sessão e Carregamento Total

Toda vez que o navegador for reiniciado, uma nova aba for aberta ou a página for recarregada (`F5` / `Ctrl+R`), o jogo deve **reiniciar seu estado do zero** (Nível 1, 0 XP, 0 Biomassa, 1 ponto de passiva disponível, 0 passivas alocadas, Zona 1 sem desafios extras e simulação oceânica renovada).

### 4.1. Arquitetura do Mecanismo de Sessão e Detecção de Carregamento Total da Tela

```mermaid
sequenceDiagram
    autonumber
    participant Browser as Browser (Window / DOM)
    participant SessionMgr as Gerenciador de Sessão (App.jsx)
    participant API as Backend Express (/api/game/session/init)
    participant DB as SQLite WAL

    Browser->>SessionMgr: Evento de Boot / Recarregamento da Página (load / pageshow)
    SessionMgr->>SessionMgr: Detecta tipo de navegação (PerformanceNavigationTiming: reload | navigate)
    SessionMgr->>SessionMgr: Gera novo sessionId único (ex.: sess_<timestamp>_<uuid>)
    SessionMgr->>SessionMgr: Salva sessionId em sessionStorage e window.__SHARKTANK_SESSION__
    SessionMgr->>API: POST /api/game/profile/reset { mode: 'full', sessionId, navigationType }
    API->>DB: Reseta jogador_build (Nv.1, XP 0, Biomassa 0, Passivas []) + mapa_config (Tier 1)
    DB-->>API: Estado limpo confirmado
    API-->>SessionMgr: Retorna perfil zerado + metadados { sessionId, resetAt }
    Browser->>SessionMgr: document.readyState === 'complete' + 1º frame do Canvas renderizado
    SessionMgr->>Browser: Marca data-session-id e data-screen-fully-loaded="true" no DOM
```

### 4.2. Especificação Técnica do Mecanismo no Frontend (`client/src/App.jsx`)

1. **Geração e Registro da Sessão Atual (`sessionId`):**
   * No carregamento do aplicativo, gerar um identificador único para a sessão de página atual:
     ```javascript
     function createPageSessionInfo() {
       const navEntry = performance.getEntriesByType?.('navigation')?.[0];
       const navType = navEntry?.type || 'navigate'; // 'navigate' | 'reload' | 'back_forward'
       const previousSessionId = sessionStorage.getItem('sharktank_session_id');
       const sessionId = `st_${Date.now().toString(36)}_${Math.random().toString(36).substring(2, 8)}`;

       sessionStorage.setItem('sharktank_session_id', sessionId);
       sessionStorage.setItem('sharktank_previous_session_id', previousSessionId || 'none');
       sessionStorage.setItem('sharktank_loaded_at', new Date().toISOString());

       return {
         sessionId,
         previousSessionId,
         navigationType: navType,
         isReload: navType === 'reload' || Boolean(previousSessionId),
         loadedAt: new Date().toISOString(),
         screenFullyLoaded: false
       };
     }
     ```
2. **Detecção de Quando o Jogo Recarregou Totalmente a Tela (`screenFullyLoaded`):**
   * O estado `screenFullyLoaded` só passa para `true` quando **ambas** as condições abaixo forem satisfeitas:
     1. O evento de carregamento completo da janela (`document.readyState === 'complete'` / `window.addEventListener('load', ...)`) tiver concluído; **e**
     2. O backend tiver confirmado o reset completo da sessão (`POST /api/game/profile/reset` com `mode: 'full'`) e os dados iniciais da árvore e do oceano estiverem renderizados na tela.
   * Expor esses atributos de forma inspecionável no DOM principal (`.abyssal-app-shell`) e no objeto global `window.__SHARKTANK_SESSION__`:
     * `data-session-id={sessionInfo.sessionId}`
     * `data-navigation-type={sessionInfo.navigationType}`
     * `data-screen-loaded={screenFullyLoaded ? 'true' : 'false'}`
   * Exibir também na Topbar uma pílula discreta de status da sessão (`.session-status-pill`) indicando visualmente que a sessão atual está ativa e a tela foi 100% carregada (ex.: `● Sessão Ativa`).

### 4.3. Especificação Técnica no Backend (`server/src/index.js`)
* No endpoint `POST /api/game/profile/reset` (quando `mode === 'full'`):
  * Resetar `jogador_build` (`nivel = 1`, `xp_atual = 0`, `xp_proximo_nivel = 100`, `biomassa = 0`, `pontos_passiva_disponiveis = 1`, `nos_passivas_json = '[]'`, `habilidades_equipadas_json = '["snap_strike", "tail_sweep"]'`).
  * Resetar `mapa_config` (`tier = 1`, `dificuldade_calculada = 10.0`, `densidade_peixes_max = 14`, `afixos_json = '[]'`, `status = 'em_andamento'`).
  * Limpar `historico_expedicoes`, `peixes` e `peixes_comidos` para garantir que nenhum dado residual de sessões anteriores permaneça.
  * Retornar no JSON de resposta o objeto `session`:
    ```json
    {
      "success": true,
      "session": {
        "sessionId": "st_...",
        "resetConfirmed": true,
        "resetTimestamp": "2026-11-05T..."
      }
    }
    ```
